# Project Rules

This project is an admin platform starter (FastAPI + React) for LabCD.

See [README.md](./README.md) for how to run the stack and how to add admin modules.

Goals

- readable code
- maintainable
- dockerized
- production ready

Rules

- Keep code simple.
- Never overengineer.
- Never write business logic inside React.
- Never duplicate code.
- One responsibility per function.
- Use descriptive names.
- Use Docker.
- Use environment variables.
- Keep files small.
- Explain every major change.
